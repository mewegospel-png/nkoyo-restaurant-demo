# Nkoyo Website Demo

A concept website created as a sales demo for Nkoyo, Abuja.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository, e.g. `nkoyo-website-demo`.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the public Pages URL.

## Client-demo note
This is a concept/demo. Before a production launch, confirm the supplied contact details, menu/pricing/hours, add approved restaurant photography, connect the real reservation/order system, and obtain the restaurant's approval.
